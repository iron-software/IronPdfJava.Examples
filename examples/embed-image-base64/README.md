***Based on <https://ironpdf.com/examples/embed-image-base64/>***

IronPDF offers the capability to seamlessly incorporate images into PDF documents:

- Image Files
- `System.Drawing.Image`
- `System.Drawing.Bitmap`

This feature is particularly beneficial for embedding images directly within the document without the need to retrieve external assets during [HTML to PDF conversion](https://ironpdf.com/tutorials/html-to-pdf/).
