IronPDF for Java offers functionality for modifying the orientation of PDF pages in both new and existing documents.

When generating new PDFs, IronPDF defaults to a portrait orientation. However, developers have the flexibility to customize this using a `ChromePdfRenderOptions` instance. By applying the `setPaperOrientation` method, which takes a `PaperOrientation` value, developers can specify the orientation of the generated PDF to their preference. In the code snippet provided, lines 21 - 23 demonstrate setting a PDF document to landscape orientation by calling `setPaperOrientation` with `PaperOrientation.LANDSCAPE` on line 21. Changing the enumeration value to `PaperOrientation.PORTRAIT` would adjust the upcoming call to `PdfDocument.renderUrlAsPdf` to produce the [IronPDF homepage](https://ironpdf.com) in portrait orientation.

For altering the orientation of existing PDFs—such as those generated by previous rendering calls or loaded into IronPDF via the `PdfDocument.fromFile` method—`ChromePdfRenderOptions` cannot be used. Instead, PDF page orientation adjustments are possible through rotation-based transformations. IronPDF provides the `rotateAllPages` method to facilitate this.

The `rotateAllPages` method leverages a `PageRotation` enum type to define permissible rotation values. As shown in line 40 of the code example, it allows for rotating all pages in a PDF. Alternatively, to rotate specific pages or a group of pages, use the `rotatePage` method instead of the `rotateAllPages`.

The following Java code snippet illustrates how to rotate specific pages using the `rotatePage` method:

```java
existingPdf.rotatePage(PageRotation.CLOCKWISE_270, PageSelection.firstPage());  
existingPdf.rotatePage(PageRotation.CLOCKWISE_180, PageSelection.lastPage());  
existingPdf.rotatePage(PageRotation.CLOCKWISE_90, PageSelection.singlePage(8)); // Rotate page 9  
existingPdf.rotatePage(PageRotation.CLOCKWISE_270, PageSelection.pageRange(9, 14)); // Rotate pages 10 - 15
```
