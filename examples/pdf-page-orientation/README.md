IronPDF for Java allows developers to alter the page orientation of both new and existing PDF documents.

By default, new PDF documents generated with IronPDF are presented in portrait orientation. However, developers can modify this setting during the process of converting various contents like HTML, RTFs, and URLs into PDF formats using an instance of `ChromePdfRenderOptions`. The `setPaperOrientation` method in this class lets developers specify a `PaperOrientation` value to adjust the orientation of the resulting PDFs as needed. In the provided code snippet, lines 21 to 23 demonstrate setting a PDF document to landscape orientation. This is achieved by invoking `setPaperOrientation` with `PaperOrientation.LANDSCAPE` on line 21. To switch back to portrait orientation, replacing the enum value with `PaperOrientation.PORTRAIT` would configure the ensuing call to `PdfDocument.renderUrlAsPdf` to render the [IronPDF homepage](https://ironpdf.com?utm_source=github) in portrait.

It's important to note that `ChromePdfRenderOptions` instances cannot be used to modify page orientations for existing PDF documents. These documents could be `PdfDocument`s created from earlier rendering actions or loaded into IronPDF with the `PdfDocument.fromFile` method. To change the orientation of such documents, IronPDF provides the `rotateAllPages` method, which applies rotation-based transformations.

The `rotateAllPages` function accepts a `PageRotation` enum, offering specified rotation options. As exemplified in line 40 of the code example, this method can rotate each page of an existing PDF document 270 degrees clockwise. For scenarios where only specific pages need rotation, the `rotatePage` method offers a more targeted approach compared to `rotateAllPages`.
